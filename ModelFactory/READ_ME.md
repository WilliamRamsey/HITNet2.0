# Model Factory

The model factory houses the tools for training instance segmentation models.
Two primary models will be housed within this microservice: helmet detection models and field line detection models.

## Dataset.py

Houses the Dataset class that manages the annotation development process for a dataset.

~~~ Python
Dataset(path)
~~~
